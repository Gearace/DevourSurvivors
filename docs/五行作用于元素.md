# 先厘清边界
**两套独立体系，互不等同，不存在互相替代**
1. 五行（5个，物质本源）：**金、木、水、火、土**
2. 奇幻七元素（7个，能量/现象）：**风、火、水、土、雷、光、暗**
> 注意：两套体系有同名词「火/水/土」，但**含义完全不同**
> ✅ 五行之火：物质层面的燃烧本源、燥性、万物化烬的力量
> ✅ 奇幻之火：能量层面的火焰、高温能量流
> ✅ 五行之水：物质本源，润下、凝藏的物质本性
> ✅ 奇幻之水：流动液态能量、流体冲击
> ✅ 五行之土：承载、收纳、化育的大地本源
> ✅ 奇幻之土：岩石、岩土实体能量

总属性数量：5+7 = **12个独立属性**
交互类型沿用8种定义（游戏用）
| 类型 | 定义                                             | 游戏倍率              |
| ---- | ------------------------------------------------ | --------------------- |
| 增幅 | 能量同频，放大威力，消耗降低                     | ×1.5                  |
| 抵消 | 直接对冲，瞬间湮灭，大幅压制                     | ×0.3                  |
| 平衡 | 互不助长、互不破坏，共存稳定                     | ×1.0                  |
| 变异 | 二者交融诞生全新效果，基础威力不变，附加特殊机制 | ×1.0 + 特殊效果       |
| 传导 | 不提升伤害，仅扩大技能作用范围                   | ×1.0，范围+50%        |
| 庇护 | A存在时，B受到第三方属性伤害降低（buff类被动）   | 减伤30%               |
| 同化 | 持续侵蚀DOT，缓慢抹除目标身上的属性buff          | 每2秒削减20%属性强度  |
| 反噬 | 强行超负荷融合，能量失控，施法者自伤             | 释放时自损25%最大生命 |

底层逻辑原则：
1. 五行是**物质本性规则**，遵循传统五行生克（木生火，火生土，土生金，金生水，水生木；木克土，土克水，水克火，火克金，金克木）
2. 七元素是**能量现象**，没有内置五行生克，它们和五行之间做跨体系交互
3. 同名≠同一个东西：五行火≠奇幻火；五行水≠奇幻水；五行土≠奇幻土。同名只是表象，本源维度不同。

# 全部跨体系关系分析（五行 → 七元素，附带理由）
> 格式：五行属性 → 奇幻元素｜交互关系｜理由分析
## 一、五行【金】（特性：肃杀、坚硬、收敛、切割、凝实）
1. 金 → 风｜平衡
理由：金属实体不会阻挡气流，风无法侵蚀坚硬金属；金的肃杀也不能直接影响气流。二者互不增益、互不破坏。
2. 金 → 奇幻火｜抵消
理由：金质坚硬收敛，奇幻火是高温能量。高温火焰能量持续冲击金属，熔化消解金的刚性，属于能量对冲。
3. 金 → 奇幻水｜平衡
理由：普通金属遇液态水仅缓慢锈蚀，不是瞬间生克；奇幻水的流体冲击无法直接摧毁金属，金也不能直接增幅水流能量。无即时增减。
4. 金 → 奇幻土｜平衡
理由：金属藏于岩土，但五行金是物质本源；奇幻土是岩石能量。岩土可以承载金属，但不会放大金的力量，金也无法直接压制岩土能量。
5. 金 → 雷｜传导
理由：金属是电荷的优良载体。雷的电能可以借由金的物质载体扩散；金不增强雷电威力，只作为介质传导能量。
6. 金 → 光｜变异
理由：圣光照射收敛肃杀的金，淬炼出圣金，产生破甲、净化腐蚀的新效果；既不是增幅也不是抵消，交融生成新特性。
7. 金 → 暗｜变异
理由：暗影阴能侵蚀金属，催生蚀金效果，产生持续腐蚀DOT。暗影不会直接摧毁金，金也不能压制暗影，交融产生腐化新状态。

## 二、五行【木】（特性：生发、延展、生机、根系、柔韧）
1. 木 → 风｜增幅
理由：风是流动的大气能量，风可以推动草木舒展、传播种子，助长生机。大气流动与木的生发本性同频，放大木属性力量。
2. 木 → 奇幻火｜增幅、同化
理由：木是可燃物，奇幻火能量依附木的物质本源更容易燃烧，能量强度提升；长时间持续燃烧会逐步吞噬木的生机，缓慢同化木属性。
3. 木 → 奇幻水｜平衡
理由：五行木靠水润滋养，但奇幻水是流体冲击能量。奇幻水可以浇灌草木，但流体冲击本身不会放大木的威力；水浪也无法直接摧毁木的生机，互不压制。
4. 木 → 奇幻土｜抵消、同化
理由：奇幻土是岩石岩土能量，厚重岩土会压制根系伸展；但长期生长，木的根系会缓慢撕裂岩石，逐步同化岩土结构。瞬间碰撞是抵消，长期作用是同化。
5. 木 → 雷｜抵消
理由：雷电爆裂能量直接击穿、焦枯生机。雷的爆裂肃杀能量直接摧毁木的生机本源，瞬间对冲压制。
6. 木 → 光｜增幅、庇护
理由：光是阳性能量，日光滋养生机，同频放大木的力量；木的繁茂生机可以包裹圣光，缓冲暗影对光的侵蚀，给光提供庇护减伤。
7. 木 → 暗｜变异
理由：阴暗能量侵染生机，催生腐木瘴气，附带毒素持续伤害。生机与阴能融合，生成腐化毒素效果。

## 三、五行【水】（特性：润下、寒凉、渗透、凝聚）
1. 水 → 风｜传导
理由：风是大气流动，气流可以推动水体流动。风作为介质，让水的能量扩散更远，不提升威力，只扩大范围。
2. 水 → 奇幻火｜抵消、变异
理由：五行水的寒凉润下本源，压制奇幻火的高温能量，瞬间对冲削弱火焰；大量两股能量剧烈碰撞，汽化产生蒸汽爆发，触发变异。
3. 水 → 奇幻水｜增幅
理由：二者同名但维度不同。五行水是物质润下本源，奇幻水是液态流动能量。本源与现象共振，互相强化流体能量。
4. 水 → 奇幻土｜抵消、同化
理由：奇幻土岩土能量阻挡、围堵水流，瞬间对冲；长时间接触，岩土持续吸纳水分，逐步同化锁住水体能量。
5. 水 → 雷｜传导
理由：水体是导电介质，雷电能量借水扩散，伤害不变，技能范围扩大。
6. 水 → 光｜变异、反噬
理由：少量圣光融入五行水，生成圣光净水，拥有净化效果（变异）；过量强行灌注，阳光与水的阴寒本源剧烈冲突，能量失控反噬使用者。
7. 水 → 暗｜增幅、庇护
理由：暗为阴寒能量，五行水本身属阴，阴阳同频，互相放大暗影力量；五行水可以包裹暗影能量，缓冲光的净化伤害，庇护暗影。

## 四、五行【火】（特性：炎上、燥烈、消散、化万物）
1. 火 → 风｜传导
理由：气流可以携带火种，风作为介质，将火焰能量带到更远位置，威力不变，范围扩大。
2. 火 → 奇幻火｜增幅
理由：五行火是燃烧本源，奇幻火是火焰能量现象。本源与现象共鸣，火焰威力大幅增强。
3. 火 → 奇幻水｜抵消、变异
理由：五行火燥烈向上，奇幻水流体能量可降温熄灭火焰，瞬间对冲；大量能量碰撞，产生蒸汽爆炸变异效果。
4. 火 → 奇幻土｜增幅
理由：五行火焚烧万物化为土，奇幻土是岩土能量。火的燥烈能量灼烧岩石，熔为熔岩，放大岩土相关效果。
5. 火 → 雷｜变异、传导
理由：高温火焰产生等离子态，与雷电能量交融，形成等离子爆燃（变异）；等离子火焰可以作为介质传导雷电，扩大雷的范围。
6. 火 → 光｜增幅
理由：五行火自带阳气，光是阳能显化。阳能同频共振，互相放大威力。
7. 火 → 暗｜变异、反噬
理由：少量暗能量融入五行之火，生成冥火（阴火，变异）；大量阳火与阴暗能量强行混合，阴阳剧烈冲突，触发反噬。

## 五、五行【土】（特性：承载、收纳、厚重、沉降、包容）
1. 土 → 风｜抵消、同化
理由：奇幻风是气流能量，狂风冲击岩土；厚重岩土阻挡狂风，瞬间对冲；长期风化，风慢慢侵蚀岩石，同化岩土为沙尘。
2. 土 → 奇幻火｜平衡
理由：五行土承载火焰，奇幻火可以在地表燃烧。土可以容纳火焰，但不会助长火焰威力，火焰也无法直接摧毁大地本源，互不压制。
3. 土 → 奇幻水｜抵消、同化
理由：奇幻水流体冲击，岩土可以拦蓄水流，瞬间对冲；长期接触，泥土吸收水分，同化锁住水体能量。
4. 土 → 奇幻土｜增幅
理由：五行土是承载本源，奇幻土是岩石能量现象。本源与现象共振，土系能量增强。
5. 土 → 雷｜平衡
理由：大地可以承接、泄放雷电能量，容纳雷的冲击，既不放大雷电威力，也不能抵消雷电伤害。
6. 土 → 光｜变异、庇护
理由：光落入五行大地，淬炼岩土形成圣化石，获得净化、坚固特性（变异）；五行土包容万物，可以包裹光能量，缓冲暗影伤害，提供庇护。
7. 土 → 暗｜变异、庇护
理由：暗能量沉入大地，形成腐化瘴土，产生持续腐化DOT（变异）；大地收纳暗影，隔绝光的净化，庇护暗属性。
