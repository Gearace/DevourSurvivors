## 关卡设计灵感归纳 — 从 FC 到 PS5

> 目标：把「优秀关卡设计」的底层机制抽出来，落到「吞噬幸存者 v1.2」的「多大关（13 层/关）+ 多章扩展」结构上。
> 这次修订（v1.2）的核心原则：**每条设计点必须能追溯到一张归纳表里的具体作品**，归纳驱动改动，不凭空写。
> 参考作品按主机世代筛选，只列对「波次/吞噬/构筑/多章」有可移植性的设计。



### 一、可移植的设计原则（跨平台通用，先于作品）

| 原则 | 一句话 | 本作对应位置 |
|---|---|---|
| 节奏曲线 | 松-紧-松-紧交替 | 单大关 13 层难度系数 + 节点间隔 |
| 决策密度 | 每 30-60s 一次有意义选择 | 清层 4选1 + 路线 3选1 |
| 渐进揭示 | 新机制先安全教学，再高压复用 | 新敌人在普通波首现，精英波强化 |
| 风险-回报 | 危险节点给超额收益 | 精英层掉稀有材质 + 遗物 3选1 |
| 可重复性 | 同关多次游玩路径不同 | 路线 roll + 事件随机 |
| 反馈节奏 | 每次操作有即时反馈 | 吞噬/清层/升级 三段反馈 |
| 风格差异 | 不同区域 敌人+环境+机制 完全不同 | 多大关不同怪物风格（v1.2 核心） |
| 多章递进 | 章节间保留 build，难度递增 | 跨大关保留/重置规则（3.0） |

### 三、本作「有趣化」改造方案（每条标注来源作品）

#### 3.0 多大关结构总纲（杀戮尖塔 + 黑神话 + 原神 联合派生）

> **来源**：杀戮尖塔的「每章不同怪物 + 专属遗物 + build 延续」+ 黑神话的「Boss 法宝 = 关卡专属遗物」+ 原神的「圣遗物构筑」。
> 13 层不是上限，而是一个大关。多个大关串成一局游戏，每大关有独立怪物风格 + Boss + 专属遗物。

`
一局游戏 = 多大关串接, 每大关 13 层, 独立风格

大关 1 腐沼 (13层)    → Boss 腐沼吞噬者  专属遗物 毒囊之核
  风格: 慢速/群体/分裂  毒囊 分裂体  毒雾环境
大关 2 熔金矿洞 (13层) → Boss 金甲兽      专属遗物 金甲残片
  风格: 快速/切割/金元素  撕裂者 相位割者  熔岩环境
大关 3 虚空回廊 (13层) → Boss 虚空吞噬者  专属遗物 虚空碎片
  风格: 镜像/分身/佯攻  镜影 佯攻体  虚空环境
大关 4+ 无尽深渊      → 难度 ×1.25/大关, 全怪物混合
`

**跨大关保留/重置规则（杀戮尖塔式 build 延续 + 艾尔登法环死亡改世界）**
- 保留：技能空间 + 已浸篆三类卡 + 遗物 + 路线选择历史
- 重置：HP/能量 回复至 70%，材质池保留，警报归零
- 递增：每大关敌人数 ×1.1，难度系数 ×1.25

#### 3.1 节奏曲线重排（单大关内部，来源：FC 关卡门 + 忍者龙剑传限时）
- 3/6/9/12 层为「张力峰」（非战斗节点），战斗层 4/5/8/10/12 强度递增
- 大关 1 全层限时 10 min（忍者龙剑传），超时难度 +1 档
- 层 5/10 固定「双倍敌」（FC 关卡门结构）

#### 3.2 每大关「钩子」（来源：魂系列死亡惩罚 + 星之卡比收集）
- 层 6 元素谜题（黄金太阳）：随机 3 个，答对给史诗遗物
- 层 11 路线分支（杀戮尖塔）：安全线/风险线 2 选 1
- 精英层死亡保留 50% 材质（魂系列篝火）

- 全 5 材质集齐 解锁 隐藏路线节点（星之卡比）

#### 3.3 Boss 3 阶段（来源：只狼 Boss 阶段 + 黑神话法宝）
- 满血：固定技能 ×1
- 50%：弱点暴露 + 技能 ×2
- 20%：狂暴（速度 +50%，技能 ×3）+ 1 次性「忍杀」窗口
- 通关掉「法宝遗物」= 大关专属遗物（黑神话）

#### 3.4 精英层「恶魔城房间」化（来源：恶魔城固定房间 + PS2 房间结构）
- 中央 1 精英 + 4 方向门各 1 护卫
- 清护卫 → 再啃精英
- 护卫位置随层号变化（层 5：左上/右下；层 9：四面）

#### 3.5 警报机制（来源：合金装备警报等级）
- 同一层连续吞噬 5 只不受伤 → 警报 ×1
- 警报 ×1 → 下一层敌人数 +20%，×2 → +40%
- 精英层清完护卫瞬间警报清零

### 六、需要玩家验证的点

1. 节奏曲线（3.1）是否比当前「固定 + 随机」更耐玩？
2. 警报机制（3.5）会不会让玩家觉得「被惩罚」而非「被挑战」？
3. Boss 3 阶段（3.3）的「忍杀」窗口是否给玩家足够反应时间？
4. 层 11 路线分支（3.2）的风险线收益是否明显高于安全线？
5. **多大关结构（3.0）**：每大关 3 种专属遗物 + 专属 Boss 是否让玩家有「通关一个大关」的成就感？跨大关保留/重置规则是否平衡？
6. 归纳追溯表（五）是否真的让「每个改动都有出处」？如果某条改动你说不清来自哪款作品，就还没到位。
