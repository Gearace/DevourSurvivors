## 一、游戏核心机制

### 1.1 一句话定位

> **一个在竖屏上单指操控的「反幸存者」游戏 — 你不是在躲避敌人，而是在追逐、吞噬它们。**

### 1.2 核心循环

**核心循环：**

生成 → 追逐 → 吞噬 → 成长 → 更强 →（下一层，回到 生成）

**循环要素：**

| 环节 | 描述 |
|---|---|
| **1. 生成** | 波次自动刷出敌人，敌人类型和数量递增 |
| **2. 追逐** | 玩家通过摇杆移动，主动追击目标敌人 |
| **3. 吞噬** | 接触体型≤玩家的敌人即可吞噬，获得成长 |
| **4. 成长** | 掉材质 + 浸篆卡牌（进化/变异/领域）+ 合成升级熔炼，体型/技能/被动全由卡牌构筑驱动 |
| **5. 更强** | 能吞噬更大/更多敌人，形成正反馈 |

### 1.3 核心差异化

| 维度 | 传统幸存者 | 吞噬幸存者 |
|---|---|---|
| 玩家行为 | 射击 → 杀怪 | **移动追怪 → 吃掉怪** |
| 敌人行为 | 靠近玩家被击杀 | **主动逃跑，远离玩家** |
| 成长表现 | 武器升级 | **进化卡给技能 + 变异卡给形态 + 领域卡给被动 + 材质浸篆升级熔炼** |
| 操作复杂度 | 双摇杆 (移动+瞄准) | **单摇杆 + 手势** |
| 策略深度 | 武器搭配 | **卡牌构筑 + 融合进化** |

### 1.4 屏幕布局

```
┌──────────────────────────────────┐
│        技能状态栏                 │   ← 顶部窄条 (~10%)
│  [HP ███░░] [能量 ▓▓▓░] [技能×N]  │
├──────────────────────────────────┤
│                                  │
│         游戏主画面               │   ← 中部 (~75%)
│    (角色 + 敌人 + 特效)           │
│                                  │
├──────────────────────────────────┤
│       ┌────────────┐             │
│       │  虚拟摇杆   │             │   ← 底部正中 (~15%)
│       │ (半径~60px) │             │
│       └────────────┘             │
│                                  │
└──────────────────────────────────┘
```

**核心约束：**
- 竖屏 9:16，底部正中间仅有一个虚拟摇杆
- 没有任何额外按钮、开关、跳跃键
- 所有交互（移动 + 技能释放）均在摇杆内完成

### 1.5 手势矩阵

| 手势 | 触发条件 | 效果 | 冷却 |
|---|---|---|---|
| **拖拽移动** | 手指在摇杆内拖动，位移 < 30px 或速度 ≤ 150px/s | 角色朝拖拽方向移动 | 无 |
| **快速划过** | 摇杆内单次滑动，位移 ≥ 30px 且速度 > 150px/s | 沿划动方向释放**指向性技能** | 3-6s |
| **双击** | 摇杆内两次点击，间隔 < 300ms 且位置距离 < 20px | 释放**非指向性范围技能** | 6-15s |

## 二、玩家成长

### 2.0 成长总纲

**成长 5 条来源**

| 来源 | 给什么 | 触发 |
|---|---|---|
| 吃怪 | 分数 + 能量 | 每吞 1 个怪 |
| 掉材质 | 合成/浸篆/升级/熔炼原料（金木水火土） | 按敌人类型掉落（见第四章材料设计） |
| 技能（技能空间） | 主动/被动技能，未浸篆 | 通关 4 选 1（所有层） |
| 进化卡 / 变异卡 / 领域卡（浸篆产物） | 主动技能 / 形态变化 / 被动技能 | 浸篆生效，按材质品质+数量决定有效期 |
| 合成/浸篆/升级/熔炼 | 机制解锁 + 数值成长 | 持有足够对应技能/材质时 |

**体型成长（无等级）**

```
· 无经验、无等级
· 体型 = 初始 20px + **变异卡数量** × 1px + 变异卡效果
· 浸篆变异卡生效时同步体型（对应代码 sync_body_on_level_up）
```

**三条卡牌构筑（构筑途径 = 浸篆）**

```
· 卡牌线 (主动/形态): 技能 + 五行材质 + 合成/浸篆/升级/熔炼 → 进化卡（主动技能）/ 变异卡（形态变化）/ 领域卡（被动技能）
· 职业 = 玩家用三条卡牌拼出来的流派，不预设
```

**成长节奏（抽技能 / 掉落 / 曲线 / 弹窗）**

**抽技能机制**（无职业、无经验、卡牌构筑驱动）：成长完全来自卡牌构筑；卡牌经浸篆生效——进化卡（主动技能）/ 变异卡（形态变化）/ 领域卡（被动技能）；五行材质决定卡牌可跟谁合成/浸篆/升级/熔炼；元素增幅由进化卡/变异卡/领域卡提供，放大技能威力。

**通关局间休整**：清完当前层怪 → 先统计本局材质收获和得分等 → 抽技能 4 选 1 → 路线决策 3 选 1（进下一层）。玩家在休整时可以选择升级/熔炼材料、合成技能、浸篆卡牌。

**材质掉落**（原料，用于 2.2/2.3/2.4/2.5 的合成/浸篆/升级/熔炼）：basic/swift/decoy 不掉；heavy 30% 掉 1；split 40% 掉 1；精英 100% 掉 1~2（50% 偏向精英属性 + 50% 随机）；Boss 100% 掉 2~3（偏向 Boss 属性）。一局 13 层约 8~12 个材质，"集齐一对能浸篆" 是局内目标感，非必成。

**无经验成长曲线**：浸篆进化卡数量/合成 → 输出涨；变异卡 → 形态/体质提升；领域卡 → 被动增益；材质共鸣（同材质 ×1.1/张，软上限 5 张） → 该材质效果额外堆叠。

### 2.1 吞噬系统

> 本章讲「成长侧」的吞噬规则；敌人侧的「类型/行为/AI」见第三章敌人类型。

**吞噬判定**

`
玩家体型 ≥ 敌人体型 × 0.8 → 接触即吞噬
玩家体型 <  敌人体型 × 0.8 → 不能吞噬，碰撞弹开/扣血
`

**四层机制（门槛 / 进度 / 反噬 / 资源）**

| 维度 | 规则 |
|---|---|
| **门槛** | 体型 ≥ 敌×0.8 才接触即吞；不够格（重装/分裂/诱饵/Boss）需啃食进度 |
| **进度** | 大怪/Boss 需咬住啃 N 秒才吞下；敌人身上出现环形啃食进度条（替代血条），填满即被吞下；啃食时长随体型递增 |
| **反噬** | 撞到/啃比自己大的怪时，敌人扣血并推开玩家（0.5s 无敌帧） |
| **资源** | 啃大怪/Boss 持续消耗能量（每秒 -1~-2）；小怪一口吞不耗能量；能量见底 → 啃不动大怪，只能先吞小怪回能量 |

**节奏设计**：小怪一口吞（爽）→ 大怪啃 N 秒（紧，会反噬）→ Boss 啃更久（boss 战），循环成「爽-紧-爽」。

**进化卡对门槛的影响**：是否能吃更大的怪，最终由进化卡决定（如「虚空吞噬」），不是纯半径比对。

### 2.2 技能合成系统

**技能获取**

玩家在一局游戏完成后（层清完），从技能池中随机抽取 4 种技能供玩家选择 1 种。

**技能留存**

选中的技能留存在**技能空间**中，无法直接生效，需浸篆在五行材质上才可被玩家吞噬后生效（浸篆见 2.3）。

**元素分类**

技能分为七种元素：风 / 火 / 水 / 土 / 雷 / 光 / 暗。任意两种技能之间可以进行合成。

**合成规则**

- 条件：技能空间中持有 2 张及以上技能（元素任意，未进行浸篆）
- 结果：高阶或异化技能

> 具体成品配方与数值见第五章进化技能。

### 2.3 浸篆系统

浸篆不是玩家可选项，只有一个浸篆选择，浸篆后变为进化卡（主动技能）或变异卡（形态变化）或领域卡（被动技能）。

**有效期生成**

根据玩家提供的五行材质的**品质**和**数量**生成技能有效期，不提升技能效果。

- 品质越高、数量越多 → 有效期越长
- 最低：消耗 1 个最低品质五行材质 → 1 局有效
- 最高：永久有效

**失效与消耗**

一旦浸篆后，技能和材质均无法继续升级。失效后技能放回技能空间，五行材料被消耗。

**局间休整延长**

浸篆后会换算出有效期每局所消耗的五行材质品质和数量。局间休整时，可以通过消耗**同品质**五行材质 1.5 倍的每局数量来延长 1 局有效期。

**营地分解**

营地可以分解浸篆后永久有效的技能，但技能或材质只能选择保留其一。

**元素结算**

不论浸/篆，技能奇幻元素与材质五行属性均遵循 [五行作用于元素.md](五行作用于元素.md) 规范。释放技能时，按「五行材质 × 奇幻元素」交互矩阵修正最终威力。

`
进化/领域卡威力 = 技能基础威力
         × 变异卡加成（形态/体质加成）
         × 交互矩阵修正（五行材质 × 技能元素）

变异卡威力 = 角色当前形态/体质
         + 变异卡加成（形态/体质加成）
         × 交互矩阵修正（五行材质 × 技能元素）
`

### 2.4 五行相同材质升级系统

**材质品阶**

白 → 绿 → 蓝 → 紫 → 橙 → 红

**升级公式**

基础成功率 P = 100% −（目标档阶 × 10%）

| 升级 | 目标档阶 | 基础成功率 |
|---|---|---|
| 白 → 绿 | 1 档 | 90% |
| 绿 → 蓝 | 2 档 | 80% |
| 蓝 → 紫 | 3 档 | 70% |
| 紫 → 橙 | 4 档 | 60% |
| 橙 → 红 | 5 档 | 50% |

**升级消耗**

每提升一级，需额外提供**同品质同属性辅助材质 3 个**。

**失败处理**

失败时材料退回低一档。

**暴击/大成功**

依附于成功，只有成功才可能触发暴击（约 2%）/大成功（约 5%）。

- 大成功：跳过一档，蓝直冲橙
- 暴击：升级一档不变，但下次合成增加一定百分比成功率（具体数值后续考虑）

判定逻辑：先按基础成功率判定成功，成功后再 roll 特殊结果。

```csharp
if (!success) return Result.Fail;
return Rand() < 0.05 ? Result.Great : Result.Normal;
```

### 2.5 五行不同材质熔炼系统

**熔炼**

将**不同属性**的五行材质进行熔炼，产物同时具备两种属性，需计算两种属性的占比作为**背板属性**。

**熔炼后升级**

- 同品质熔炼材质可继续升级，升级时必须包含其中任意一种属性或两种属性
- 升级成功率**低于**同属性同品质材质的升级成功率
- 升级成功后，背板属性有一定几率回归单一属性材质：**单一属性占比超过 75% 时回归**

### 3.1 敌人逃跑 AI

`
行为树:

  检测与玩家距离
    │
    ├── < R1 (80px) → 全力逃跑
    │                  速度 = 最高速 × 1.3
    │                  加入随机急转弯 (Perlin Noise 扰动)
    │
    ├── < R2 (200px) → 常规逃跑
    │                  速度 = 最高速 × 1.0
    │                  稳定远离玩家
    │
    └── ≥ R2 → 游荡模式
                   速度 = 最高速 × 0.3
                   随机方向移动 + 缓慢转向

  边界处理:
    · 碰到屏幕边缘 → 沿边缘滑动，不卡住
    · 角落 → 优先逃离角落方向
    · 群体逃跑时有一定聚集倾向 (模拟 herd behavior)
`

## 四、材料设计

> 本章定义五行材质「是什么、怎么获取、怎么升级/熔炼、怎么给卡牌供能」。
> 材质特性与技能元素（七元素）的交互矩阵见 [五行作用于元素.md](五行作用于元素.md)；
> 复合材物性表见 [技能合成系统和浸篆系统.md](技能合成系统和浸篆系统.md)。

**五行材质（5 种）**

五行材质是物质本源，遵循传统五行生克（木生火 → 火生土 → 土生金 → 金生水 → 水生木；木克土、土克水、水克火、火克金、金克木）。
每种材质有固定的特性描述，浸篆后效果由「材质特性 × 技能元素」的交互矩阵决定，材质本身不预设"对应元素倾向"。

| 材质 | 核心特性（五行本性） | 克制 | 被克 |
|---|---|---|---|
| **金** | 肃杀、坚硬、收敛、切割、凝实 | 木 | 火 |
| **木** | 生发、延展、生机、根系、柔韧 | 土 | 金 |
| **水** | 润下、寒凉、渗透、凝聚 | 火 | 土 |
| **火** | 炎上、燥烈、消散、化万物 | 金 | 水 |
| **土** | 承载、收纳、化育 | 水 | 木 |

> 材质不决定技能「能不能」合成/浸篆（任意技能都可浸篆在任意材质上），只决定浸篆后的**交互矩阵修正**（见 [五行作用于元素.md](五行作用于元素.md) 跨体系关系表）。

**材质品阶（6 档）**

白 → 绿 → 蓝 → 紫 → 橙 → 红（详见 2.4 五行相同材质升级系统）

**材质获取**

材质只能通过吞怪掉落获取（见 2.0 材质掉落），无法通过商店/事件/其他途径获得。

| 来源 | 掉落概率 | 数量 | 品质倾向 |
|---|---|---|---|
| basic / swift / decoy | 0% | 0 | — |
| heavy | 30% | 1 | 白/绿 |
| split | 40% | 1 | 白/绿 |
| 精英 | 100% | 1~2 | 蓝/紫（50% 偏向精英属性） |
| Boss | 100% | 2~3 | 紫/橙（偏向 Boss 属性） |

**材质用途（配合 2.2~2.5）**

| 用途 | 章节 | 说明 |
|---|---|---|
| 浸篆（2.3） | 技能 → 进化卡/变异卡/领域卡 | 1 个最低品质材质 = 1 局；品质越高/数量越多 → 有效期越长，最高永久 |
| 升级（2.4） | 同属性材质提档 | 每提一级需额外 3 个同品质同属性辅助材质；失败退回低一档 |
| 熔炼（2.5） | 不同属性材质混合 | 产物双属性 + 背板占比；升级成功率低于同属性，背板回归单一属性阈值 75% |
| 合成（2.2） | 技能 + 材质 | 技能空间中 2 张未浸篆技能合成 → 高阶/异化技能，需浸篆后才生效 |

**材质与技能元素的关系**

技能元素（风/火/水/土/雷/光/暗）与材质五行（金/木/水/火/土）是两套独立体系。浸篆时按交互矩阵修正最终威力，同名（火/水/土）不等同。

```
结算:
  技能基础威力
  × 材质加成（浸篆材质自身五行）
  × 交互矩阵修正（五行材质 × 技能元素，见 五行作用于元素.md）
  → 最终威力
```

例：吞噬波（火元素）浸篆在**木**材质上 → 木×奇幻火 = 增幅·同化 → 威力 ×1.5 + 持续同化腐蚀木的生机。
例：黑洞牵引（水元素）浸篆在**水**材质上 → 水×奇幻水 = 增幅 → 威力 ×1.5。

## 五、进化技能

> 本章定义进化卡（主动技能）的完整规则：技能池、合成产物、浸篆结算。
> 合成/浸篆机制见 2.2/2.3；材质掉落/品质/交互矩阵见第四章材料设计 + [五行作用于元素.md](五行作用于元素.md)；复合材物性表见 [技能合成系统和浸篆系统.md](技能合成系统和浸篆系统.md)。

**技能池（11 个基础技能）**

指向性技能（划屏释放，5 个）：吞噬波 / 螺旋吞噬 / 追踪吞噬 / 黑洞牵引 / 相位切割
非指向性技能（双击释放，6 个）：影分身之术 / 影子束缚术 / 镜像领域 / 时空停滞 / 群体拉近 / 吞噬光环

每个技能自带一种奇幻元素（风/火/水/土/雷/光/暗），元素由技能池随机 roll，与技能本身无关。

**技能合成（2.2）**

- 技能空间中 2 张未浸篆技能 → 高阶/异化技能
- 合成产物元素 = 两技能元素的交互（风+火=燎原，火+水=蒸汽……共 28 种复合材）
- 复合材物性标签与地形残留见 [技能合成系统和浸篆系统.md](技能合成系统和浸篆系统.md)

**技能浸篆（2.3）**

- 技能 + 1 个五行材质 → 进化卡（主动技能）
- 材质品质+数量决定有效期（1 局 ~ 永久）
- 浸篆后技能不可继续升级；失效后技能放回技能空间，材质被消耗

**进化卡结算公式**

```
最终威力 = 技能基础威力
         × 材质加成（浸篆材质自身五行）
         × 交互矩阵修正（五行材质 × 技能元素）
```

例：吞噬波（火元素）浸篆在木材质上 → 木×奇幻火 = 增幅·同化 → 威力 ×1.5 + 持续同化腐蚀。
例：黑洞牵引（水元素）浸篆在水材质上 → 水×奇幻水 = 增幅 → 威力 ×1.5。

**进化卡 vs 变异卡 vs 领域卡**

| 类型 | 来源 | 效果 | 体型影响 |
|---|---|---|---|
| 进化卡 | 技能 + 材质浸篆 | 主动技能，威力按交互矩阵结算 | 无 |
| 变异卡 | 技能 + 材质浸篆 | 形态变化（硬化/延展/凝聚/爆发/厚重），数值加成 | +1 阶/张 |
| 领域卡 | 技能 + 材质浸篆 | 被动技能（光环/减益/护盾），持续生效 | 无 |

> 三类卡由同一技能浸篆在不同材质上产出，具体哪类由材质决定（见第四章材质特性表）。

**经典 Build 示例**

| Build | 进化卡 | 变异卡 | 领域卡 | 遗物卡 | 玩法 | 风险 |
|---|---|---|---|---|---|---|
| 金系熔金流 | 吞噬波(金) + 相位切割(金) | 熔金裂刃·重 | 凝土结界 | 雷引 | 高攻速连斩 | 无控制 |
| 水系渊海流 | 黑洞牵引(水) + 群体拉近(水) | 渊海漩涡 | 水缚 | 水缚 | 大范围水吸 | 输出低 |
| 木火生发流 | 影分身(木) + 吞噬光环(火) | 木火生发 | 火引 | 火引 | 持续灼烧 | 前期脆 |
| 土系凝土流 | 时空停滞(土) + 影子束缚(土) | 凝土结界 | 土盾 | 土盾 | 高抗性自保 | 缺爆发 |

## 六、遗物技能

> 遗物卡按稀有度分档，被动构筑，不可融合，精英层/Boss 层通关掉落 + 商店购买。
> 遗物卡对卡牌提供数值加成（持续时间、效果提升、能量/血量等），是构筑的「放大器」层。

**稀有度分档（5 档）**

| 稀有度 | 数量 | 效果池 |
|---|---|---|
| 普通 | 12 | 血量+10% / 能量上限+2 / 啃食速度+10% / 挣脱率-10% / 低血回血 |
| 罕见 | 10 | 开局无敌 3s / 啃食进度加快 20% / 对敌减速 15% / 对敌流血 / 材质抗性（某材质减伤 30%） |
| 史诗 | 8 | 元素增幅（某元素技能 ×1.5）/ 能量回速+50% / 啃食挣脱率=0 / 同材质进化卡共鸣 ×1.2 |
| 传说 | 5 | 元素增幅（×1.5 + 额外机制）/ 开局回满 / 低血无敌 / 所有材质抗性+20% |
| 神器 | 3 | 技能无冷却（仅耗能）/ 进化卡融合必成 / 同材质共鸣 ×1.3 |

**掉落规则**

| 关卡 | 掉落方式 | 稀有度 roll |
|---|---|---|
| 普通层 | 进化卡 4 选 1（无遗物） | — |
| 精英层 | 进化卡 4 选 1 + 遗物 3 选 1 | 普通 60% / 罕见 30% / 史诗 9% / 传说 1% |
| Boss 层 | 进化卡 4 选 1 + 遗物 3 选 1 | 保底 1 个史诗以上，其余 2 个偏高稀有度 |

**商店**

花分数购买遗物卡（普通 50 分 / 罕见 150 分），全章商店最多 2 个。

**遗物卡设计原则**

- 遗物卡不改变技能本身（技能元素/材质/交互矩阵不变），只提供**数值 buff**
- 数值 buff 作用于卡牌威力公式：`最终威力 × 遗物卡数值加成`
- 遗物卡不可融合/浸篆/升级/熔炼，是纯粹的被动层
- 局间休整时遗物卡自动生效，无需手动选择
