## 一、核心概念

### 1.1 一句话定位

> **一个在竖屏上单指操控的「反幸存者」游戏 — 你不是在躲避敌人，而是在追逐、吞噬它们。**

### 1.2 核心循环

`
  生成 → 追逐 → 吞噬 → 掉材质 → 通关抽卡 → 融合/镶嵌 → 更强
  ↑                                                        │
  └──────────────── 下一层路线决策 ←────────────────────────┘
`

**循环要素：**

| 环节 | 描述 |
|---|---|
| **生成** | 波次自动刷出敌人，敌人类型和数量递增 |
| **追逐** | 玩家通过摇杆移动，主动追击目标敌人 |
| **吞噬** | 接触体型≤玩家的敌人即可吞噬，获得成长 |
| **成长** | 掉材质 + 选进化卡/遗物卡 + 融合镶嵌，体型/技能/被动全由卡牌构筑驱动 |
| **更强** | 能吞噬更大/更多敌人，形成正反馈 |

### 1.3 核心差异化

| 维度 | 传统幸存者 | 吞噬幸存者 |
|---|---|---|
| 玩家行为 | 射击 → 杀怪 | **移动追怪 → 吃掉怪** |
| 敌人行为 | 靠近玩家被击杀 | **主动逃跑，远离玩家** |
| 成长表现 | 武器升级 | **进化卡给技能 + 遗物卡给被动 + 材质融合镶嵌** |
| 操作复杂度 | 双摇杆 (移动+瞄准) | **单摇杆 + 手势** |
| 策略深度 | 武器搭配 | **卡牌构筑 + 融合进化** |

## 二、操作设计

### 2.1 屏幕布局

`
┌──────────────────────────────────┐
│        技能状态栏                 │   ← 顶部窄条 (~10%)
│  [HP ███░░] [能量 ▓▓▓░] [技能×N]  │
├──────────────────────────────────┤
│                                  │
│         游戏主画面               │   ← 中部 (~75%)
│    (角色 + 敌人 + 特效)           │
│                                  │
├──────────────────────────────────┤
│       ┌────────────┐             │
│       │  虚拟摇杆   │             │   ← 底部正中 (~15%)
│       │ (半径~60px) │             │
│       └────────────┘             │
│                                  │
└──────────────────────────────────┘
`

**核心约束：**
- 竖屏 9:16，底部正中间仅有一个虚拟摇杆
- 没有任何额外按钮、开关、跳跃键
- 所有交互（移动 + 技能释放）均在摇杆内完成

### 2.2 手势矩阵

| 手势 | 触发条件 | 效果 | 冷却 |
|---|---|---|---|
| **拖拽移动** | 手指在摇杆内拖动，位移 < 30px 或速度 ≤ 150px/s | 角色朝拖拽方向移动 | 无 |
| **快速划过** | 摇杆内单次滑动，位移 ≥ 30px 且速度 > 150px/s | 沿划动方向释放**指向性技能** | 3-6s |
| **双击** | 摇杆内两次点击，间隔 < 300ms 且位置距离 < 20px | 释放**非指向性范围技能** | 6-15s |

## 三、吞噬与敌人系统

### 3.1 吞噬判定

`
吞噬条件:
  玩家体型 ≥ 敌人体型 × 0.8 → 接触即吞噬
  玩家体型 <  敌人体型 × 0.8 → 不能吞噬，碰撞弹开/扣血

设 0.8 阈值的原因:
  → 给玩家"能吃"的安全感
  → 略微小于玩家的敌人也能吞，增加爽快感
  → 保留"有些敌人暂时不能吃"的策略性
`

### 3.2 吞噬四层机制（门槛 / 进度 / 反噬 / 资源）

> 设计目标：让「吞」拥有武器系统里的「消耗与压力」，而不只是「吃就变大」。

「吞」没有 HP 条，但有它的等价物——四个维度一起支撑战斗感：

| 武器系统里 | 吞噬系统里 | 维度 | 作用 |
|---|---|---|---|
| 打不过要磨血 | 够格才咬得动（体型门槛） | **门槛** | 决定能不能啃 |
| 持续输出磨血 | 大怪要持续啃 N 秒才吞下 | **进度** | 决定啃多久 |
| 走位失误吃伤害 | 撞到比自己大的怪 → 你受伤 | **反噬** | 危险层 |
| 技能费能量/卡 CD | 啃大怪持续耗能量，啃不动 | **资源管理** | 节奏决策 |

#### 3.2.1 体型门槛（能不能吞）

- 保留现有 0.8 倍规则：`玩家体型 ≥ 敌人体型 × 0.8` 才能接触即吞。
- 够格的敌人（小怪/迅捷）= 一口吞，维持爽感，不消耗能量。
- 不够格的（重装/分裂/诱饵/Boss）= 需「啃食进度」，且啃食期间有反噬。
- 是否能吃更大的怪，最终由**进化卡**决定（如「虚空吞噬」），不是纯半径比对。体型是成长表现，不是唯一通行证。

#### 3.2.2 啃食进度（吞多久）

- 大怪/Boss 不能一口吞，需**咬住啃 N 秒**才吞下；期间它继续挣扎逃，甚至反噬。
- 视觉：敌人身上出现**环形啃食进度条**（替代血条），填满即被吞下。
- 啃食时长随敌人体型递增，Boss 最长（形成 boss 战节奏）。
- 节奏设计：小怪一口吞（爽）→ 大怪啃 N 秒（紧，会反噬）→ Boss 啃更久（boss 战），循环成「爽-紧-爽」。

#### 3.2.3 反噬（啃的时候你疼不疼）

- 撞到/啃比自己大的怪时，敌人反噬扣你血并把你推开（现有 0.5s 无敌帧机制可复用）。
- 这是「危险层」：玩家不能无脑贴大怪，必须权衡。

#### 3.2.4 资源管理（能量 = 啃食的燃料）

- 把「能量」做成**啃食燃料**：啃大怪/Boss 时**持续消耗**能量（如每秒 -1~-2）。
- 小怪一口吞**不耗能量**（维持爽感）。
- 能量见底 → 啃不动大怪，只能先吞小怪回能量（「吞小怪回能量」即「能量虹吸」卡的原始效果，正好接上）。
- 产生节奏决策：`攒能量 → 咬住大怪 → 一边啃一边被反噬扣血 → 啃完拿收益 → 能量空了退回吞小怪回能`。
- 与卡牌「虚空之眼」（技能耗能量、每 5s 回 1）同源，统一能量体系。

#### 3.2.5 敌人类型 → 机制映射

| 类型 | 体型倍率 | 一口吞 | 啃食 | 反噬 | 能量 | 吞噬收益 |
|---|---|---|---|---|---|---|
| **小兵** | 1.0x | ✅ | 无 | 无 | 不耗 | +1 分数 / +1 能量 |
| **迅捷** | 0.8x | ✅ | 无 | 无 | 不耗 | +0.5 分数 |
| **重装** | 1.5x | ❌ | 短啃 (~2s) | 啃食时被推开 | 慢耗 | +3 分数 (30% 掉材质) |
| **分裂** | 1.2x | ❌ | 中啃 (~3s) | 无 | 慢耗 | +1.5 分数 (吞下时分裂 2 小兵, 40% 掉材质) |
| **诱饵** | 2.0x | ❌ | 中啃 | 靠近后缩小逃跑 | 中耗 | 陷阱（几乎无收益） |
| **Boss** | 5.0x | ❌ | 长啃 (boss 战) | 强反噬 | 高耗 | +10 分数 / 必掉进化卡+遗物卡+材质 2~3 |

### 3.3 敌人类型

| 类型 | 颜色 | 体型倍率 | 行为特征 | 吞噬收益 |
|---|---|---|---|---|
| **小兵** | 绿色 | 1.0x | 正常逃跑，速度中等 | +1 分数 |
| **迅捷** | 黄色 | 0.8x | 逃跑速度快，转向笨拙 | +0.5 分数 |
| **重装** | 红色 | 1.5x | 逃跑慢，玩家需先成长才能吃 | +3 分数 / 30% 掉材质 |
| **分裂** | 紫色 | 1.2x | 被吞噬时分裂成 2 个小兵 | +1.5 分数 / 40% 掉材质 |
| **诱饵** | 粉色 | 2.0x | 看起来很大，靠近后缩小逃跑 | 陷阱 |
| **Boss** | 金色 | 5.0x | 层13 章节 Boss | +10 分数 / 必掉卡+材质 |

> 注：各类型在「一口吞 / 啃食 / 反噬 / 能量」上的差异见 3.2.5 映射表。

### 3.4 敌人逃跑 AI

`
行为树:

  检测与玩家距离
    │
    ├── < R1 (80px) → 全力逃跑
    │                  速度 = 最高速 × 1.3
    │                  加入随机急转弯 (Perlin Noise 扰动)
    │
    ├── < R2 (200px) → 常规逃跑
    │                  速度 = 最高速 × 1.0
    │                  稳定远离玩家
    │
    └── ≥ R2 → 游荡模式
                   速度 = 最高速 × 0.3
                   随机方向移动 + 缓慢转向

  边界处理:
    · 碰到屏幕边缘 → 沿边缘滑动，不卡住
    · 角落 → 优先逃离角落方向
    · 群体逃跑时有一定聚集倾向 (模拟 herd behavior)
`

## 四、成长与构筑总纲（单一事实源）

> 本章是全篇成长模型的唯一锚点。其它章节涉及"怎么变强"时只引用本章，不另立规则。

### 成长 5 条来源

| 来源 | 给什么 | 触发 |
|---|---|---|
| 吃怪 | 分数 + 能量 | 每吞 1 个怪 |
| 掉材质 | 融合/镶嵌原料（金木水火土） | heavy 30% / split 40% / 精英·Boss 100% |
| 进化卡 | 主动技能 + 体型同步 | 通关 4 选 1 |
| 遗物卡 | 被动 / 抗性 / 元素增幅 | 精英·Boss 通关 3 选 1 |
| 融合/镶嵌 | 机制解锁 | 持两张可融/镶嵌进化卡时 |

### 体型成长（无等级）

`
· 无经验、无等级
· 体型 = 初始 20px + 进化卡数量 × 1px (每张进化卡 +1 阶)
· 进化卡选择时同步体型 (对应代码 sync_body_on_level_up)
· 营地「进化」= 免费抽 1 张进化卡 → 体型 +1 阶
`

### 两条构筑线

`
· 进化卡线 (主动): 技能 + 五行材质 + 融合/镶嵌 → 输出/机制
· 遗物卡线 (被动): 数值 buff + 抗性 + 元素增幅 → 生存/放大
· 职业 = 玩家用两条线拼出来的流派, 不预设
`

## 五、卡牌构筑规则（进化卡 + 遗物卡）

> 本章是**卡牌构筑的单一事实源**。全篇其它章节涉及卡牌时统一引用本章。
> 两套牌组：**进化卡**（主动技能，可融合/镶嵌）与**遗物卡**（被动构筑，不可融合）。
> 

### 5.1 进化卡（主动技能 · 可融合/镶嵌）

进化卡 = 第七章技能池 × 五行材质。每张进化卡自带一个材质，材质决定它能跟谁融合/镶嵌，以及它的属性倾向。

`
· 通关奖励 4 选 1（所有层）
· 同类融合: 两张同材质 → 高阶成品，威力 ×1.4
· 相生镶嵌: 两张相生材质 → 变异成品，威力不变，解锁独有机制
· 材质共鸣: 同材质卡越多，该材质效果叠加 (×1.1/张, 软上限 5 张)
`

### 5.2 遗物卡（被动构筑 · 不可融合 · 5 档稀有度）

遗物卡只在**精英层/Boss 层**通关掉落 + 商店购买，提供被动 buff/抗性/元素增幅。

`
稀有度: 普通 / 罕见 / 史诗 / 传说 / 神器
效果池:
  · 血量类: 最大生命+ / 开局回满 / 低血回血
  · 能量类: 能量上限+ / 回能速度+
  · 状态 buff: 开局无敌 / 啃食进度加快 / 挣脱率↓
  · 状态 debuff (给敌人): 减速 / 流血 / 易伤
  · 材质抗性: 对某五行材质技能减伤/免疫
  · 元素增幅: 放大某元素技能威力 (×1.5)
`

### 5.3 五行材质 × 元素增幅 — 两套独立体系

> 关键：五行材质（金木水火土，进化卡属性）与元素增幅（风火水土雷光暗，遗物卡效果）是**两套独立体系，互不等同**。同名（火/水/土）只是表象，维度不同。

`
进化卡材质 (五行, 物质本源):
  金 / 木 / 水 / 火 / 土
  相生链: 木生火 → 火生土 → 土生金 → 金生水 → 水生木

遗物卡元素增幅 (奇幻七元素, 能量现象):
  风 / 火 / 水 / 土 / 雷 / 光 / 暗

结算顺序 (释放技能时):
  基础威力
  → 材质加成 (进化卡自身五行)
  → 元素增幅 (遗物卡放大某元素)
  → 交互矩阵修正 (五行材质 × 奇幻元素, 见附录 D)
`

### 5.4 经典 Build 示例

#### Build 1：金系熔金流
`
进化卡: 吞噬波(金) + 相位切割(金) → 熔金裂刃·重
遗物卡: 雷引 (雷/金系技能 +30%)
玩法: 高攻速金系连斩, 雷引放大威力
风险: 金系无控制, 面对大群敌人吃紧
`

#### Build 2：水系渊海流
`
进化卡: 黑洞牵引(水) + 群体拉近(水) → 渊海漩涡
遗物卡: 水缚 (某水控遗物, 控制时间+50%)
玩法: 大范围水吸+禁锢, 站撸清屏
风险: 输出偏低, 依赖控制链
`

#### Build 3：木火生发流
`
进化卡: 影分身(木) + 吞噬光环(火) → 相生镶嵌 木生火
遗物卡: 火引 (火系技能 +30%)
玩法: 木注入火, 分身放灼烧光环, 持续伤害
风险: 前期脆弱, 需苟到成型
`

#### Build 4：土系凝土流
`
进化卡: 时空停滞(土) + 影子束缚(土) → 凝土结界
遗物卡: 土盾 (所有材质抗性+20%)
玩法: 全屏冻结+束缚, 高抗性自保
风险: 缺乏爆发, Boss 战可能超时
`

## 六、成长与抽卡机制 (无职业 · 无经验 · 卡牌构筑驱动)

### 6.1 设计原则

`
· 无职业、无经验、无等级系统
· 成长完全来自卡牌构筑 (build)
· 两张独立牌组: 进化卡 (主动技能) + 遗物卡 (被动构筑)
· 五行材质 (金/木/水/火/土) 决定进化卡能跟谁融合/镶嵌
· 元素增幅 (风/火/水/土/雷/光/暗) 由遗物卡提供, 放大技能威力
· 两套体系独立, 同名不等同 (五行火 ≠ 奇幻火)
`

### 6.2 进化卡 (Evolution Card)

主动技能, 可融合/镶嵌, 通关奖励 4 选 1。

`
材质 (五行, 5 种): 金/木/水/火/土，各自属性见第八章材质效果表。

技能池 (取自第七章技能池):
  · 吞噬波 / 螺旋吞噬 / 追踪吞噬 / 黑洞牵引 / 相位切割
  · 影分身之术 / 影子束缚术 / 镜像领域 / 时空停滞
  · 群体拉近 / 吞噬光环

池子 = 11 技能 × 5 材质 = 55 张
`

#### 进化卡融合/镶嵌

同类融合 (两张同材质进化卡):
`
· 威力 ×1.4 + 材质专属加成
· 例: 吞噬波(金) + 相位切割(金) → 熔金裂刃 (金系重斩, 范围+50%)
`

相生镶嵌 (两张相生材质进化卡, 按五行相生):
`
相生链: 木生火 → 火生土 → 土生金 → 金生水 → 水生木
· 基础威力不变, 解锁该相生对独有机制
· 具体配方清单见第八章 8.2
`

### 6.3 遗物卡 (Relic Card)

被动构筑, 不可融合, 按稀有度分档, 精英层/Boss 层通关掉落 + 商店购买。

`
稀有度 (5 档):
  普通 / 罕见 / 史诗 / 传说 / 神器

效果池:

| 啃食时长 | 12s |

| 通关后 | 结算界面（总分/吞噬数/用时）；触发「永恒之环」可保留 1 张卡进下一局 |

### 9.4 难度双维度模型

```
节点总难度 = 层号系数 × 节点类型系数 × 节奏修正

层号系数（手调台阶，前松后紧）:
  层 1-4   → 1.0
  层 5-6   → 1.15
  层 7-8   → 1.30
  层 9-10  → 1.50
  层 11-12 → 1.75
  层 13    → 2.0（Boss）

节点类型系数:
  普通波 1.0 / 精英 1.6 / 营地 0.3 / 商店 0.5 / 事件(战斗) 1.2 / 事件(剧情) 0.5

节奏修正:
  连续 2 层选营地/商店 → 下一普通波 ×1.2（防全安全路线）
  连续 2 层选精英     → 解锁 1 次免费营地（补偿高风险）
```

> 实现：`GameManager.difficulty_multiplier` 从公式 `1.0 + (wave-1)*0.15`
> 改为查层号系数表 × 当前节点类型系数。
> 敌人数量/速度/AI 按层号系数缩放；精英/Boss 按自身体型 + 节点系数额外缩放。

### 9.5 章节与无尽模式

```
章节 1: 13 层，基础敌人，Boss = 金甲兽
章节 2: 13 层，敌人速度 +20%，新增「佯攻」AI，Boss = 虚空吞噬者
章节 3: 13 层，新增 2 种敌人类型，Boss = 深渊巨口
章节 4+: 无尽模式，Boss 体型 ×1.5，敌人全属性 ×1.25
```

- 章节间保留 build（卡牌不重置），HP/能量回复至 70%。
- 无尽模式每 13 层为一章，循环递增。

## 附录 D: 五行材质 × 奇幻元素 交互矩阵

> 来源: 《五行作用于元素》。进化卡材质（五行）与遗物卡元素增幅（奇幻七元素）在技能结算时按本矩阵修正。
> 同名（火/水/土）两套维度不同，不等同。

### 交互类型

| 类型 | 定义 | 游戏倍率 |
|---|---|---|
| 增幅 | 能量同频，放大威力，消耗降低 | ×1.5 |
| 抵消 | 直接对冲，瞬间湮灭，大幅压制 | ×0.3 |
| 平衡 | 互不助长、互不破坏，共存稳定 | ×1.0 |
| 变异 | 交融诞生新效果，基础威力不变，附加特殊机制 | ×1.0 + 特殊 |
| 传导 | 不提升伤害，仅扩大范围 | ×1.0, 范围+50% |
| 庇护 | A 存在时 B 受第三方属性伤害降低 | 减伤 30% |
| 同化 | 持续侵蚀 DOT，缓慢抹除目标属性 buff | 每 2s 削 20% |
| 反噬 | 强行超负荷融合，施法者自伤 | 释放时自损 25% 最大生命 |

### 跨体系关系表（五行 → 奇幻七元素）

| 五行\元素 | 风 | 奇幻火 | 奇幻水 | 奇幻土 | 雷 | 光 | 暗 |
|---|---|---|---|---|---|---|---|
| 金 | 平衡 | 抵消 | 平衡 | 平衡 | 传导 | 变异 | 变异 |
| 木 | 增幅 | 增幅·同化 | 平衡 | 抵消·同化 | 抵消 | 增幅·庇护 | 变异 |
| 水 | 传导 | 抵消·变异 | 增幅 | 抵消·同化 | 传导 | 变异·反噬 | 增幅·庇护 |
| 火 | 传导 | 增幅 | 抵消·变异 | 增幅 | 变异·传导 | 增幅 | 变异·反噬 |
| 土 | 抵消·同化 | 平衡 | 抵消·同化 | 增幅 | 平衡 | 变异·庇护 | 变异·庇护 |

### 结算公式

`
最终威力 = 基础威力
         × 材质加成 (进化卡自身五行)
         × 元素增幅 (遗物卡, 若该元素匹配)
         × 交互矩阵修正 (五行材质 × 奇幻元素)

例: 吞噬波(金) 命中「雷」元素区域
  = 基础 × 金加成 × (雷引遗物?×1.5) × 传导(×1.0, 范围+50%)
`
