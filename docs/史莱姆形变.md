### 史莱姆纯物理形变

通过改变自身形状、密度、弹性、黏度和接触面积来产生不同效果。

### 核心属性

史莱姆的物理形变可以围绕四个基础属性来设计：

| 属性       | 作用                 | 影响                   |
| ---------- | -------------------- | ---------------------- |
| **弹性**   | 反弹、跳跃、缓冲     | 越高越弹，越低越黏     |
| **黏度**   | 附着、缠绕、拖拽     | 越高越容易粘住物体     |
| **密度**   | 重量、冲击、抗压     | 越高越重，越低越轻     |
| **延展性** | 拉伸、变薄、穿过缝隙 | 越高越能变形，但越脆弱 |

玩家通过调整这四个属性，组合出不同形变动作。

### 纯物理形变能力

#### 1. 扁平化

史莱姆压扁自己，贴在地面、墙面或天花板上。
用于钻过低矮通道、躲避上方攻击、贴墙移动。压扁后移动变慢，但受击面积变小，也不容易被击飞。

#### 2. 拉伸

史莱姆把身体拉长，像黏液触手一样伸出去。
可以抓住远处的拉杆、边缘、平台，或者把远处的物体拉过来。拉伸越长越细，越容易被切断或打断。

#### 3. 弹跳

史莱姆压缩身体后突然释放，像橡胶球一样弹出去。
可以弹过沟壑、撞击敌人、从高处落地缓冲。压缩时间越长，弹得越远，但蓄力期间不能移动。

#### 4. 包裹

史莱姆展开身体包住物体或敌人。
包住小型物体可以搬运；包住敌人可以限制行动、降低速度；包住武器可以削弱攻击力。包裹体积越大，自身移动越慢。

#### 5. 硬化

史莱姆提高局部密度，让表面变硬。
可以在撞击时增加伤害，或者在受击时减少伤害。硬化后弹性下降，不能立刻弹跳；持续太久会消耗大量体力。

#### 6. 液化

史莱姆降低密度和黏度，让身体更接近流体。
可以穿过栅栏、窄缝、排水口，也能从高处摔落时减少伤害。液化时无法攻击，受到强冲击会被打散。

#### 7. 分裂

史莱姆把身体分成几小块，每块都能独立移动一小段距离。
适合同时踩多个机关、绕到敌人背后、探路。分裂后每块都很脆弱，被击中就会消失，需要时间重新合体。

#### 8. 融合

多个小史莱姆或史莱姆碎片重新合并。
可以恢复完整形态，也可以把分裂出去的部分收回。融合瞬间会产生一次冲击波，推开附近小型物体。

#### 9. 吸附

史莱姆提高黏度，让自己牢牢粘住某个表面。
可以倒挂天花板、攀附光滑墙面、固定住滑动的平台。吸附时不能快速移动，但能抵抗强风和击退。

#### 10. 冲击团块

史莱姆把身体压缩成一个高密度团块，然后高速砸向目标。
适合破墙、击碎木箱、打断敌人动作。使用后需要短暂恢复，不能连续使用。

### 形变之间的克制关系

- **弹性高**：适合跳跃、反弹，但容易被黏住。
- **黏度高**：适合攀爬、缠绕，但移动慢。
- **密度高**：适合撞击、抗压，但跳不高、游不动。
- **延展性高**：适合钻缝、抓取，但容易被切断。

玩家不需要切换成“火形态”“冰形态”，而是根据场景调整史莱姆的物理状态：遇到高墙就弹跳，遇到窄缝就液化，遇到敌人就包裹，遇到机关就分裂。

### 限制方式

- 每次形变消耗**体力或结构稳定性**。
- 极端形变维持时间短，比如拉得太长会断。
- 分裂后碎片脆弱，容易被范围攻击清除。
- 硬化后不能立刻液化，液化后不能立刻硬化。
- 包裹大型敌人时，自身会被拖慢甚至 immobilize。

这样史莱姆的能力会非常“物理”：它不靠元素，不靠拟态，不靠复制别人，只靠自己的身体结构变化来解决战斗、探索和解谜。



以下按**物理原理**分类，提供一批纯形变能力。每条均基于史莱姆自身的体积、形状、密度、弹性、黏度、表面张力、内压与拓扑结构变化，不涉及元素、拟态或复制他人。

### 一、体积与密度（质量不变，改占位）

| 能力         | 效果                | 玩法用途                   |
| ------------ | ------------------- | -------------------------- |
| **压缩**     | 体积缩小、密度升高  | 变小钻缝、加重踩踏、抗击飞 |
| **膨胀**     | 体积变大、密度降低  | 卡住门框、撑开裂缝、当浮体 |
| **局部增密** | 只在接触点增重      | 一拳重击、压住杠杆一端     |
| **空心化**   | 内部充气成泡        | 漂浮、当气囊缓冲坠落       |
| **分层密度** | 外轻内重 / 外重内轻 | 不倒翁式自稳、或高速翻滚   |
| **重心偏移** | 把质量挪到身体一侧  | 自动翻身、甩尾、失衡撞击   |
| **质心下沉** | 贴地低重心          | 抗推抗吹、顶住移动平台     |
| **失重态**   | 整体密度接近空气    | 缓慢升空、越过高墙（限时） |

### 二、形状与拓扑（改几何，不改成分）

- **薄片化**：压成一张膜，贴地滑行、从门下穿过、盖住陷阱口。
- **细丝化**：拉成一根长线，穿针引线般过锁孔、绕住敌人脚踝。
- **球化**：收成完美圆球，滚动加速、最小受击面。
- **柱化**：变成柱子，撑住塌落的天花板、顶起闸门。
- **锥化**：前端收成尖锥，集中压强凿穿木板或冰面。
- **楔形**：插进裂缝后膨胀，劈开石墙、撑断锁链。
- **环形/甜甜圈**：中间留孔，套住柱子、栏杆、敌人脖子或武器柄。
- **管状/中空管**：当吸管抽水、当管道导流、套在喷口上 redirect 气流。
- **漏斗形**：收集散落物品、导引液体或沙砾。
- **伞形/伞盖**：接住落石、挡上方投射物、缓降。
- **碗形**：盛水、盛钥匙、当临时容器。
- **多足化**：底部伸出几条粗腿，提高稳定性、跨过低矮障碍。
- **棘刺化**：表面凸起硬刺（高密度局部），增加穿刺伤害、防被吞。
- **锯齿边缘**：旋转时切割绳索、藤蔓、木栅栏。
- **波浪边**：身体边缘起伏，增加摩擦抓地、或在沙地“划水”前进。
- **分叉/Y形**：同时勾住两个支点、拉开两扇门。
- **螺旋/钻头**：旋转前进，钻入土堆、木墙、雪堆。
- **折叠/手风琴**：身体折成多层，蓄能后瞬间弹出。
- **网格/网膜**：拉成带孔的网，捞取物品、拦截飞行物、兜住落石。
- **口袋/囊袋**：体内形成封闭腔，装道具、保护小生物、隔绝噪音。
- **双腔/多腔**：分成几个独立气室，一个破了还能维持形态。
- **中空壳**：外壳硬化、内部空，当盾牌或当掩体让别人躲进去。
- **镜像对称破坏**：故意做成不对称，产生偏转弹道、斜向滑行。

### 三、弹性与能量（储能—释能）

- **蓄力压缩**：压扁蓄能，释放时弹射（可蓄可取消）。
- **反弹**：高弹性撞墙反弹，连续弹跳跨越地形。
- **阻尼化**：极低弹性，吸收冲击，从高处落地无伤。
- **弹簧化**：把自己做成弹簧，连跳、把队友弹上去。
- **橡皮筋**：两端固定后拉伸，储存势能，松开时把自己或物体甩出去。
- **鞭打**：细长形态快速回弹，末端速度极高，抽打、断绳、打落武器。
- **共振**：以特定频率振动，震碎玻璃、震松砖块、打断施法读条。
- **减振垫**：垫在机关下，让压力板不触发。
- **动能回收**：受击时存一部分动能，下次攻击释放。
- **钟摆**：挂住高点摆动，荡过深坑。
- **陀螺稳定**：高速自旋保持姿态，抗击退、在水面直立行走。
- **陀螺仪倾倒**：故意失稳，用倾倒的角动量撞倒敌人。
- **弹性势能陷阱**：把自己绷在两个墙面之间，敌人经过时释放。

### 四、黏度与表面（界面作用）

- **高黏附着**：粘墙、粘天花板、粘住敌人武器。
- **零黏滑移**：表面极滑，让敌人抓不住、从束缚中滑脱。
- **选择性黏附**：只粘特定材质（对金属黏、对石头不黏），用于解谜。
- **黏液桥**：在两点间拉起一条黏丝，当绳索通行。
- **黏液锚**：射出黏团固定一点，再收缩把自己拉过去。
- **黏液手套**：包住手增加摩擦力，攀爬光滑井壁。
- **润滑层**：在地面铺一层，让敌人滑倒、让重物易推。
- **表面张力膜**：水面行走、封住瓶口、封住漏水处。
- **毛细爬升**：沿细缝、布料、纸张向上渗透。
- **剥离撕扯**：粘住后反向撕离，带走敌人表层（剥甲、剥苔藓、揭封印纸）。
- **黏性捕获**：粘住飞行箭矢、飞镖、投掷物。
- **反黏脱壳**：被抓住时留下一层外壳，本体溜走（蜕皮）。

### 五、流体动力学（流动与压力）

- **蠕动推进**：靠体内波状收缩前进，无声、可贴地。
- **喷射推进**：从后端喷出自身液体，短时冲刺或空中变向。
- **虹吸**：把远处液体吸过来（抽干水池露出钥匙）。
- **液压臂**：体内加压，像液压缸一样顶起重物。
- **水锤**：管内流体急停产生冲击力，震开阀门。
- **涡流**：旋转搅动周围流体，卷走小型敌人、聚拢物品。
- **层流贴附**：贴着壁面流动减少阻力，快速绕行。
- **射流切割**：高压细流切断绳索、蜡烛、薄木板。
- **气泡裹送**：包住空气泡带着物体上浮。
- **沉降分离**：静置后重的部分下沉，用于筛选吞下的物品。
- **毛细封堵**：渗进机关缝隙使其卡死。
- **压强均衡**：潜入深水时内外压平衡，抗压不扁。
- **真空囊**：排出内部气体形成负压，吸住光滑平面、拔起石板。

### 六、分裂与重组（拓扑不连续的玩法）

- **二等分**：分成两半，各做一件事（踩双机关）。
- **碎粒化**：散成几十颗小球，覆盖一片区域、探路、穿格栅。
- **主从体**：一大带几小，小的被击碎不影响主体。
- **接力传递**：碎片依次传递物品或信号。
- **分布式感知**：碎片铺开当“地毯传感器”，侦测整片区域。
- **诱饵分身**：留一团假身体引敌，本体潜走。
- **合体冲击**：多个碎片同时撞一点，爆发伤害。
- **缝合再生**：碎片召回重组，恢复血量。
- **寄生附着**：一小块粘在敌人身上，后续召回时把敌人拖回来。
- **桥梁化**：碎片排成一行，搭成临时阶梯。
- **链式融合**：碎片首尾相连成链，套住敌人或当鞭子。
- **牺牲断尾**：主动断开被抓住的部分逃脱。

### 七、结构力学（把自己当机械零件）

- **活塞**：往复伸缩，推动拉杆、打气、泵水。
- **阀门**：堵住或开通管道，控制水流方向。
- **密封圈/垫片**：填满缝隙止漏、止气、隔音。
- **万向节**：连接两个物体并允许转动，修好断掉的机构。
- **铰链/合页**：把自己当门轴。
- **轴承**：垫在重物下减少摩擦，推动巨石。
- **配重块**：挂在杠杆另一端平衡重量谜题。
- **滑轮替代**：绕过棱角改变拉力方向。
- **拱/支撑架**：撑起坍塌空间，救人或开路。
- **桁架**：分散受力，承受比自重大得多的载荷。
- **减震器**：装在移动平台上，让平台平稳通过尖刺区。
- **离合器**：连接/断开两个转动部件。
- **飞轮**：储存旋转动能，维持机构运转。
- **楔锁**：卡进齿轮让它停转。
- **缓冲包**：包住锋利机关刃，安全通过。

### 八、感官与信息（物理感知，非魔法）

- **震动传导**：贴地感知远处脚步、判断方向与体重。
- **触须探路**：伸出细丝探测前方有无陷阱、测深度。
- **薄膜听音**：拉成鼓膜状，听隔壁房间对话。
- **压力感应**：脚下感知地面硬度变化，发现暗门。
- **温度梯度感知**：感觉气流方向、找到通风口（不靠火元素，只靠温差传导）。
- **形变记忆**：记录曾通过的路线形状，原路返回。
- **回声定位**：敲击自身产生声波，探测密闭空间轮廓。
- **张力反馈**：黏丝上感知拉力变化，判断是否有人触碰。

### 九、战斗应用（纯物理的控制与伤害）

- **包裹窒息**：罩住头部阻断呼吸（对无呼吸敌人无效）。
- **绞杀收紧**：环状缠绕后收缩，持续伤害+减速。
- **缴械**：粘住武器后猛拉或旋转夺械。
- **吞刃**：包住刀刃降低其锋利度与伤害。
- **关节锁**：渗入关节缝隙，限制敌人动作。
- **蒙眼**：糊住敌人头部或传感器，致盲。
- **绊索**：地面拉一条细丝，绊倒冲锋敌人。
- **钉刺反伤**：表面硬化尖刺，近战攻击者受伤。
- **弹反**：高弹性曲面把投射物原路弹回。
- **偏转装甲**：斜面外形让攻击滑开，降低命中伤害。
- **冲击锤**：全身压缩后砸下，破盾、破甲、破地板。
- **投石索**：把自己当弹药被投出，或抛出自身一部分。
- **人肉沙袋**：包住队友吸收一次致命伤害。
- **反弹台**：让队友踩着自己弹到高处。
- **拖拽**：粘住后往回拉，把敌人拖进陷阱或水里。
- **叠罗汉**：多层堆叠增加高度或重量。
- **滚压**：球化后高速滚过，碾压小型敌人。
- **震荡波**：落地瞬间把冲击通过地面传导，震倒一片。

### 十、探索与机关解法（软钥匙）

- **填坑**：流进凹陷处铺平路面。
- **堵喷口**：封住蒸汽/箭矢喷口，安全通过。
- **导电前的准备**：把自己拉成线连通两个电极（自身不发电，只做导体通路）。
- **水位调节**：堵住排水口抬高水位，浮起物品。
- **镜面替代**：拉成光滑曲面反射光线（解谜用，非光元素）。
- **称重作弊**：站上秤盘增加重量，触发重力机关。
- **影子遮蔽**：膨胀挡住光源，改变光影机关。
- **声学阻断**：塞满共鸣腔，停止发声机关。
- **钥匙复制**：渗入锁孔取得齿形印象，再用硬化部分当临时钥匙。
- **印章拓印**：拓下浮雕图案，用于门禁验证。
- **绳结替身**：把自己打成结，固定两段绳索。
- **浮标**：标记深水路线或暗流方向。
- **计时器**：缓慢流动的黏液滴漏，用于同步多个机关。

### 十一、代价与风险（设计平衡用）

- **拉伸断裂**：拉太长会断，断掉的部分需要时间回收。
- **失水干涸**：高温干燥环境体积持续流失，能力减弱。
- **低温变脆**：弹性下降，硬化后受重击会碎裂。
- **离心甩散**：高速旋转过久会甩出碎片，失去质量。
- **过度压缩**：内压过高会失控喷溅，短暂无法成形。
- **黏度过高**：移动迟缓，且容易粘住不该粘的东西（自己的脚、队友）。
- **液化脆弱**：液态时被强冲击打散，会被水流冲走。
- **分裂脆弱**：碎片血量极低，范围攻击直接清空。
- **形态切换冷却**：硬化后不能立刻液化，液化后不能立刻弹跳。
- **质量守恒**：变大就变稀变弱，变硬就变小变重，永远有取舍。
- **暴露核心**：某些形态会让内部核心外露，成为弱点。
- **惯性惩罚**：重型形态转向慢、刹车距离长。

### 十二、组合技思路（两条物理规则叠加）

- 压缩 + 喷射 = 火箭跳
- 细丝 + 高黏 = 蛛网陷阱

### 十三、成长线建议（解锁顺序）

1. **基础三态**：球、片、丝（移动、钻缝、抓取）
2. **弹性系**：压缩、弹跳、反弹
3. **黏度系**：附着、滑移、黏液桥
4. **密度系**：压缩增重、空心漂浮
5. **分裂系**：二等分、碎粒、合体
6. **结构系**：液压、楔、密封、支撑
7. **高阶**：共振、涡流、射流、真空吸附
8. **极限**：碎粒化、蜕皮、动能回收

如果将这些能力组合成“形变槽 + 四维属性（弹性/黏度/密度/延展）”的系统，玩家只需调整滑块而非切换形态，操作会更纯粹。
