### 三、几条设计规律（让玩家能推理，不用死记）

1. **相克对 → 高反应产物**：水火得蒸汽（推开）、光暗得黄昏（中和）、雷土得磁石（转化）。这类产物通常**改变战场状态**而非单纯加伤。
2. **同性相邻 → 强化**：风火、水土这类“一个提供介质、一个提供能量”的组合，产物保留两者特征且**范围扩大**。
3. **暗系参与 → 持续/削弱型**：黑炎、浊毒、腐壤、咒雷全是DOT或debuff，定位清晰，不会和光系打架。
4. **光系参与 → 控制/净化型**：极光、虹露、裁决都带“信息层面”效果（致盲、净化、暴露），避免光只是“另一种火”。
5. **土是唯一的“固态稳定剂”**：凡与土合成，产物都可作为**地形/平台**存在（熔岩地表、晶簇墙、磁石锚点），适合做解谜支点。
6. **黄昏作为兜底**：光+暗=黄昏，效果减半但属性通吃。这是给卡关玩家的软解法，也避免了“必须刷齐所有元素”的挫败。

### 四、接回你的「五材印」系统

既然技能要篆在材质上才生效，这张表可以直接当**材质合成树**用：

- **基础材**：风、火、水、土、雷、光、暗七种素坯。
- **复合材**：两两压印得到蒸汽板、熔岩坯、磁石、晶簇等，**同一技能篆在不同复合材上效果不同**（比如“弹跳”篆在磁石上会吸附金属，篆在晶簇上会折射分光）。
- **三相扩展**：若允许三材叠印，可做“熔岩+雾=黑曜石”“激流+磁石=电磁泵”这类高阶分支，深度留给后期。
- **回收成本**：复合材溶印后退回基础材时**有损耗**，防止玩家无限试错穷举表格。

## 同一技能在不同复合材上的差异

这里的核心原则在于：**技能永远不变，变的只是介质**。术式只提供“压缩—释放”“包裹”“分裂”这类纯物理动作，元素效应全部由材质结算。如此设计的好处是玩家只需掌握一套操作手感，搭配不同材质即可衍生出数十种玩法，无需重新学习动作。

### 一、底层公式：一次「印」的结算顺序

```
1. 术式本体（物理动作）执行
2. 读取材质的物性标签（导热/导电/密度/相变/光学/摩擦）
3. 按标签改写：轨迹 / 范围 / 持续时间 / 附加态
4. 材质反过来对史莱姆付代价（烧水、失重、磁化……）
5. 地形残留（有的材用完就没了，有的会留下持久场）
```

关键在于第4步：**材质不是免费buff，它要向史莱姆收税**。这能避免“选最强材料”的最优解固化。

### 四、反向视角：同一材质上的共性（教玩家建立直觉）

与其死记28×6的表格，不如让玩家记住**材质的性格**：

- **气态四材（罡风/雾/岚/阴风）**：统统改**轨迹和视野**，不改伤害。适合探索与控场。
- **液态四材（深海/泥/激流/浊毒）**：统统改**持续性和范围**，代价是机动性。适合阵地战。
- **固态四材（岩核/沙/磁石/晶簇）**：统统改**命中判定和结构互动**（碎、反射、吸附、削甲）。适合解谜。
- **高能四材（炎核/超载/等离子/裁决）**：统统是**爆发＋自伤**。适合斩杀，不适合常用。
- **暗系四材（黑炎/腐壤/深渊/咒雷）**：统统是**DOT或干扰**，且多数能反噬自己。
- **光系三材（耀斑/圣焰/虹露）**：统统是**信息层效果**（照明、净化、治疗），极少加伤。
- **黄昏**：永远是“减半但通吃”。它是卡关解法，不是最优解。

### 五、三个必须做的边界处理

1. **同名材质不能叠加**。同一块坯上不能同时印“熔岩”和“深海”——它们会互相中和成“岩核＋蒸汽”两小块废料。这条规则直接防止了穷举最强组合。
2. **材质会被消耗**。熔岩会冷、雾会散、超载会泄。同一块材有“耐久”，用几次后退回素坯，逼玩家循环溶印。
3. **史莱姆自身的物理状态要参与结算**。同样是“弹跳·磁石”，压缩态（重）吸得慢但撞得狠，液化态（轻）被直接吸过去贴住。**材质×自身态**构成第二层组合，深度立刻翻倍，而且完全是你之前那套纯物理形变的延伸。
