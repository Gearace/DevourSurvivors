## 关卡设计灵感归纳 — 从 FC 到 PS5

> 目标：把「优秀关卡设计」的底层机制抽出来，落到「吞噬幸存者 v1.2」的 13 层路线 + 多章扩展上，让每大关有可感知的风格差异和递进，而不是 13 个同质节点循环。
> 参考作品按主机世代筛选，只列对「波次/吞噬/构筑」有可移植性的设计。
>
> **v1.1 修订（2026-10-23）：确认本作采用杀戮尖塔式「大关（13 层）+ 多章扩展」结构，每大关有独立怪物风格。**
> 第 3.0 节「大关结构总纲」先于 3.1-3.5 的 13 层内部改造；第 4 节把多章扩展列为最高优先级 P0。

---

### 一、可移植的设计原则（跨平台通用）

| 原则 | 一句话 | 本作对应位置 |
|---|---|---|
| 节奏曲线 | 松-紧-松-紧交替，每 3 波一个张力峰 | 13 层难度系数 + 节点类型间隔 |
| 决策密度 | 每 30-60s 一次有意义选择 | 清层 4选1 + 路线 3选1 |
| 渐进揭示 | 新机制先「安全环境」教学，再「高压环境」复用 | 新敌人在普通波首现，精英波强化 |
| 风险-回报 | 危险节点给超额收益 | 精英层掉落稀有材质 + 遗物 3选1 |
| 可重复性 | 同章多次游玩路径不同 | 路线 roll + 事件随机 |
| 反馈节奏 | 每次操作有即时视觉/数值反馈 | 吞噬/清层/升级 三段反馈 |
| 风格差异 | 不同区域/章节 敌人+环境+机制 完全不同 | 多大关不同怪物风格（v1.1 新增） |

### 二、按主机世代的作品归纳

#### FC (1983-1988)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 迷宫探索 + 有限道具 | 层数有限道具 | 营地节点给 1 次性消耗道具 |
| 横版「关卡门」结构 | 每层门后敌人数翻倍 | 层号 5/10 固定为「双倍敌」层 |

#### SFC (1990-2001)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 塞尔达：多区域 + 钥匙/能力解锁 | 能力解锁改变探索方式 | 进化卡改变玩家移动/吞噬能力 → 后续层敌人布局适配 |
| 恶魔城：固定房间结构 + Boss 门 | 房间即层，Boss 门即第 13 层 | 每 4 层一个小 Boss（精英变体），13 层大 Boss |
| 星之卡比：收集全 → 开门 | 收集材质 → 解锁路线选项 | 全 5 材质集齐 解锁 1 个 隐藏路线节点 |

#### PS1 (1994-2006)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 合金装备：潜入 + 警报等级 | 玩家行为触发难度 | 吞噬连续 N 只 → 警报升级 → 下一层敌人数 +20% |
| 魂系列：死亡惩罚 + 篝火 | 检查点 + 资源损失 | 精英层死亡 → 保留 50% 材质 + 3 选 1 重新进入 |

#### N64 / Dreamcast (1996-2004)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 黄金太阳：元素解谜 | 五行×七元素交互 | 事件节点给「元素谜题」选择，答对得高额遗物 |
| 塞尔达时之笛：迷宫 + 能力门 | 能力门分层 | 进化卡 = 能力，不同卡开不同精英层（高伤害卡开高精英层） |

#### PS2 (2000-2013)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 忍者龙剑传：无存档高压 | 限时通关 | 章节 1 全层限时 10 min，超时难度 +1 档 |
| 恶魔城：房间结构 | 房间即层 | 精英层 = 「恶魔城房间」：4 扇方向门 + 中央精英 |

#### PS3/PS4 (2006-2020)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 只狼：Boss 战 + 忍杀 | Boss 阶段 + 弱点 | Boss 3 阶段：满血无弱点 → 50% 暴露弱点 → 20% 狂暴 |
| 塞尔达旷野：开放世界 + 化学引擎 | 元素反应 | 材质熔炼 → 元素反应（水+火=蒸汽，推开敌人） |
| 原神：元素反应 + 圣遗物构筑 | 反应链 + 圣遗物 | 技能合成 → 元素反应 + 遗物 = 圣遗物 |

#### PS5 / 当前 (2020+)
| 作品 | 借鉴机制 | 移植到本作 |
|---|---|---|
| 艾尔登法环：死亡 - 世界状态改变 | 死亡 → 下一局路线微调 | 死亡 → 重开时保留 1 张牌 + 路线 +1 难度档 |
| 黑神话：Boss 机制 + 法宝 | Boss 技能 + 法宝 | Boss 法宝 = 大关专属遗物 |
| 杀戮尖塔：关卡结构 + 多章扩展 | 每章不同怪物 + 专属遗物 | 多大关不同怪物风格 + 专属遗物（v1.1 核心） |

### 三、本作「有趣化」改造方案（v1.1 双层结构）

**双层：先定义「多大关骨架（3.0）」，再填充「单大关内部 13 层节奏（3.1-3.5）」。**

#### 3.0 多大关结构总纲（杀戮尖塔式）

**核心思路：13 层不是上限，而是一个大关。多个大关串成一局游戏，每大关有独立怪物风格 + Boss + 专属遗物。**

`
┌─ 一局游戏 ─────────────────────────────────────────────────┐
│                                                              │
│  大关 1: 腐沼 (13 层)  →  Boss: 腐沼吞噬者                  │
│    风格: 慢速/群体/分裂   毒囊   分裂体   毒雾环境            │
│    专属遗物: 毒囊之核 (吞噬分裂体不掉 20%)                   │
│                                                              │
│  大关 2: 熔金矿洞 (13 层)  →  Boss: 金甲兽                  │
│    风格: 快速/切割/金元素   撕裂者   相位割者   熔岩环境     │
│    专属遗物: 金甲残片 (金系技能威力 +20%)                    │
│                                                              │
│  大关 3: 虚空回廊 (13 层)  →  Boss: 虚空吞噬者              │
│    风格: 镜像/分身/佯攻   镜影   佯攻体   虚空环境           │
│    专属遗物: 虚空碎片 (开局 1 张 镜像类技能)                 │
│                                                              │
│  大关 4+: 无尽深渊 (13 层循环, 难度 ×1.25/大关)             │
│    风格: 全怪物混合 + 强化   每大关 roll 2 种               │
│    专属遗物: 深渊回响 (随机 1 个 大关专属遗物)               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
`

**每大关内部 13 层模板（可复用，按风格微调）**

| 层 | 节点 | 说明 |
|---|---|---|
| 1 | 普通（教学）| 本大关风格首现，教学 1 个机制 |
| 2 | 普通（双敌变体）| 敌人数 +1，引入 2 种本风格敌人 |
| 3 | 营地（1选1）| 治疗 / 小遗物 / 熔炼 1 选 1 |
| 4 | 普通（三敌围猎 + 精英预演）| 教学精英机制 |
| 5 | 精英（首次）| 护卫 ×2 + 1 精英 |
| 6 | 事件（元素谜题）| 答对得史诗遗物 |
| 7 | 营地（1选1）| 合成 / 熔炼 / 治疗 |
| 8 | 商店（2 遗物）| 价格按大关难度递增 |
| 9 | 精英（精英 ×2，护卫 ×3）| |
| 10 | 普通（高压层）| 3×基础 + 1 分裂，本大关风格强化 |
| 11 | 事件（路线分支）| 安全线 / 风险线 2 选 1 |
| 12 | 精英（精英 ×2 + 护卫 ×3，高难度）| |
| 13 | Boss（3 阶段）| 本大关 Boss + 专属遗物 |

**大关差异（杀戮尖塔式「同模板不同皮」）**

| 维度 | 大关 1 腐沼 | 大关 2 熔金矿洞 | 大关 3 虚空回廊 | 大关 4+ 无尽 |
|---|---|---|---|---|
| 敌人风格 | 慢速群体 | 快速切割 | 镜像分身 | 全混合强化 |
| 新机制 | 毒囊 (吞噬后 8s -3HP/s) | 撕裂者 (4s 撕裂波) | 镜影 (召唤 2 分身) | roll 2 种 |
| 环境 | 毒雾 (每 30s 1 片 -5HP) | 熔岩 (地面残留灼烧) | 虚空 (视野-30%) | 每大关 roll 1 环境 |
| 难度曲线 | 基础 | 速度 +20% | 新 AI + 2 种敌人 | 全属性 ×1.25/大关 |
| Boss | 腐沼吞噬者 | 金甲兽 | 虚空吞噬者 | 深渊回响体 |
| 专属遗物 | 毒囊之核 | 金甲残片 | 虚空碎片 | 深渊回响 |

**跨大关保留/重置规则（杀戮尖塔式 build 延续）**

- 保留：技能空间 + 已浸篆三类卡 + 遗物 + 路线选择历史
- 重置：HP/能量 回复至 70%，材质池保留，警报归零
- 递增：每大关敌人数 ×1.1，难度系数 ×1.25

#### 3.1 节奏曲线重排（单大关内部）

> 说明：3.1 的 13 层节奏曲线是**每个大关内部**的节点顺序，多大关之间按 3.0 的「多大关结构总纲」串接。

节奏点：3/6/9/12 层为「张力峰」（非战斗节点），战斗层 4/5/8/10/12 强度递增。

#### 3.2 每大关「钩子」（同章多次游玩可感知不同）
- 层 6 事件：随机 3 个元素谜题（水+火=蒸汽 / 金+木=? / ...），答对给 史诗遗物
- 层 11 路线分支：2 条路线，选「安全线」（普通+营地）或「风险线」（精英+事件，遗物 ×2）
- 大关 2 新增：层 4 变为「多形态层」（同种敌人 3 种行为，先吞噬哪种决定后续）

#### 3.3 Boss 阶段化（每大关 Boss 都 3 阶段）
- 满血：固定技能 ×1
- 50%：弱点暴露 + 技能 ×2
- 20%：狂暴（速度 +50%，技能 ×3），给 1 次性「忍杀」机会（高爆发伤害）

#### 3.4 精英层「恶魔城房间」化
- 中央 1 精英 + 4 方向门各 1 护卫
- 玩家必须清护卫 → 再啃精英
- 护卫位置随层号变化（层 5：左上/右下；层 9：四面）

#### 3.5 警报机制（合金装备）
- 同一层连续吞噬 5 只不受伤 → 警报 ×1
- 警报 ×1 → 下一层敌人数 +20%，×2 → +40%
- 精英层清完护卫瞬间警报清零

### 四、落地优先级（按改动量 / 收益）

| 优先级 | 改动 | 改动量 | 收益 |

| P0 | 每大关 3 种专属遗物 + 专属 Boss（3.0）| 扩 card_database 遗物池 + wave_spawner Boss 数据 | 构筑深度 |

| P0 | Boss 3 阶段（3.3）| 改 wave_spawner + enemy_base | Boss 战有张力 |

### 五、需要玩家验证的点

1. 节奏曲线（3.1）是否比当前「固定 + 随机」更耐玩？
2. 警报机制（3.5）会不会让玩家觉得「被惩罚」而非「被挑战」？
3. Boss 3 阶段（3.3）的「忍杀」窗口是否给玩家足够反应时间？
4. 层 11 路线分支（3.2）的风险线收益是否明显高于安全线？
5. **多大关结构（3.0）**：每大关 3 种专属遗物 + 专属 Boss 是否让玩家有「通关一个大关」的成就感？多大关之间的保留/重置规则是否平衡？
