## 一、游戏核心机制

### 1.1 一句话定位

> **一个在竖屏上单指操控的「反幸存者」游戏 — 你不是在躲避敌人，而是在追逐、吞噬它们。**

### 1.2 核心循环

**核心循环：**

生成 → 追逐 → 吞噬 → 成长 → 更强 →（下一层，回到 生成）

**循环要素：**

| 环节 | 描述 |
|---|---|
| **1. 生成** | 波次自动刷出敌人，敌人类型和数量递增 |
| **2. 追逐** | 玩家通过摇杆移动，主动追击目标敌人 |
| **3. 吞噬** | 接触体型≤玩家的敌人即可吞噬，获得成长 |
| **4. 成长** | 掉材质 + 浸篆卡牌（进化/变异/领域）+ 合成升级熔炼，体型/技能/被动全由卡牌构筑驱动 |
| **5. 更强** | 能吞噬更大/更多敌人，形成正反馈 |

### 1.3 核心差异化

| 维度 | 传统幸存者 | 吞噬幸存者 |
|---|---|---|
| 玩家行为 | 射击 → 杀怪 | **移动追怪 → 吃掉怪** |
| 敌人行为 | 靠近玩家被击杀 | **主动逃跑，远离玩家** |
| 成长表现 | 武器升级 | **进化卡给技能 + 变异卡给形态 + 领域卡给被动 + 材质浸篆升级熔炼** |
| 操作复杂度 | 双摇杆 (移动+瞄准) | **单摇杆 + 手势** |
| 策略深度 | 武器搭配 | **卡牌构筑 + 融合进化** |

### 1.4 屏幕布局

```
┌──────────────────────────────────┐
│        技能状态栏                 │   ← 顶部窄条 (~10%)
│  [HP ███░░] [能量 ▓▓▓░] [技能×N]  │
├──────────────────────────────────┤
│                                  │
│         游戏主画面               │   ← 中部 (~75%)
│    (角色 + 敌人 + 特效)           │
│                                  │
├──────────────────────────────────┤
│       ┌────────────┐             │
│       │  虚拟摇杆   │             │   ← 底部正中 (~15%)
│       │ (半径~60px) │             │
│       └────────────┘             │
│                                  │
└──────────────────────────────────┘
```

**核心约束：**
- 竖屏 9:16，底部正中间仅有一个虚拟摇杆
- 没有任何额外按钮、开关、跳跃键
- 所有交互（移动 + 技能释放）均在摇杆内完成

### 1.5 手势矩阵

| 手势 | 触发条件 | 效果 | 冷却 |
|---|---|---|---|
| **拖拽移动** | 手指在摇杆内拖动，位移 < 30px 或速度 ≤ 150px/s | 角色朝拖拽方向移动 | 无 |
| **快速划过** | 摇杆内单次滑动，位移 ≥ 30px 且速度 > 150px/s | 沿划动方向释放**指向性技能** | 3-6s |
| **双击** | 摇杆内两次点击，间隔 < 300ms 且位置距离 < 20px | 释放**非指向性范围技能** | 6-15s |

## 二、玩家成长

### 2.0 成长总纲

**成长 5 条来源**

| 来源 | 给什么 | 触发 |
|---|---|---|
| 吃怪 | 分数 + 能量 | 每吞 1 个怪 |
| 掉材质 | 合成/浸篆/升级/熔炼原料（金木水火土） | 按敌人类型掉落（见第四章材料设计） |
| 技能（技能空间） | 主动/被动技能，未浸篆 | 通关 4 选 1（所有层） |
| 进化卡 / 变异卡 / 领域卡（浸篆产物） | 主动技能 / 形态变化 / 被动技能 | 浸篆生效，按材质品质+数量决定有效期 |
| 合成/浸篆/升级/熔炼 | 机制解锁 + 数值成长 | 持有足够对应技能/材质时 |

**体型成长（无等级）**

```
· 无经验、无等级
· 体型 = 初始 20px + **变异卡数量** × 1px + 变异卡效果
· 浸篆变异卡生效时同步体型（对应代码 sync_body_on_level_up）
```

**三条卡牌构筑（构筑途径 = 浸篆）**

```
· 卡牌线 (主动/形态): 技能 + 五行材质 + 合成/浸篆/升级/熔炼 → 进化卡（主动技能）/ 变异卡（形态变化）/ 领域卡（被动技能）
· 职业 = 玩家用三条卡牌拼出来的流派，不预设
```

**成长节奏（抽技能 / 掉落 / 曲线 / 弹窗）**

**抽技能机制**（无职业、无经验、卡牌构筑驱动）：成长完全来自卡牌构筑；卡牌经浸篆生效——进化卡（主动技能）/ 变异卡（形态变化）/ 领域卡（被动技能）；五行材质决定卡牌可跟谁合成/浸篆/升级/熔炼；元素增幅由进化卡/变异卡/领域卡提供，放大技能威力。

**通关局间休整**：清完当前层怪 → 先统计本局材质收获和得分等 → 抽技能 4 选 1 → 路线决策 3 选 1（进下一层）。玩家在休整时可以选择升级/熔炼材料、合成技能、浸篆卡牌。

**材质掉落**（原料，用于 2.2/2.3/2.4/2.5 的合成/浸篆/升级/熔炼）：basic/swift/decoy 不掉；heavy 30% 掉 1；split 40% 掉 1；精英 100% 掉 1~2（50% 偏向精英属性 + 50% 随机）；Boss 100% 掉 2~3（偏向 Boss 属性）。一局 13 层约 8~12 个材质，"集齐一对能浸篆" 是局内目标感，非必成。

**无经验成长曲线**：浸篆进化卡数量/合成 → 输出涨；变异卡 → 形态/体质提升；领域卡 → 被动增益；材质共鸣（同材质 ×1.1/张，软上限 5 张） → 该材质效果额外堆叠。

### 2.1 吞噬系统

> 本章讲「成长侧」的吞噬规则；敌人侧的「类型/行为/AI」见第三章敌人类型。

**吞噬判定**

`
玩家体型 ≥ 敌人体型 × 0.8 → 接触即吞噬
玩家体型 <  敌人体型 × 0.8 → 不能吞噬，碰撞弹开/扣血
`

**四层机制（门槛 / 进度 / 反噬 / 资源）**

| 维度 | 规则 |
|---|---|
| **门槛** | 体型 ≥ 敌×0.8 才接触即吞；不够格（重装/分裂/诱饵/Boss）需啃食进度 |
| **进度** | 大怪/Boss 需咬住啃 N 秒才吞下；敌人身上出现环形啃食进度条（替代血条），填满即被吞下；啃食时长随体型递增 |
| **反噬** | 撞到/啃比自己大的怪时，敌人扣血并推开玩家（0.5s 无敌帧） |
| **资源** | 啃大怪/Boss 持续消耗能量（每秒 -1~-2）；小怪一口吞不耗能量；能量见底 → 啃不动大怪，只能先吞小怪回能量 |

**节奏设计**：小怪一口吞（爽）→ 大怪啃 N 秒（紧，会反噬）→ Boss 啃更久（boss 战），循环成「爽-紧-爽」。

**进化卡对门槛的影响**：是否能吃更大的怪，最终由进化卡决定（如「虚空吞噬」），不是纯半径比对。

### 2.2 技能合成系统

**技能获取**

玩家在一局游戏完成后（层清完），从技能池中随机抽取 4 种技能供玩家选择 1 种。

**技能留存**

选中的技能留存在**技能空间**中，无法直接生效，需浸篆在五行材质上才可被玩家吞噬后生效（浸篆见 2.3）。

**元素分类**

技能分为七种元素：风 / 火 / 水 / 土 / 雷 / 光 / 暗。任意两种技能之间可以进行合成。

**合成规则**

- 条件：技能空间中持有 2 张及以上技能（元素任意，未进行浸篆）
- 结果：高阶或异化技能

> 具体成品配方与数值见第五章进化技能。

### 2.3 浸篆系统

浸篆不是玩家可选项，只有一个浸篆选择，浸篆后变为进化卡（主动技能）或变异卡（形态变化）或领域卡（被动技能）。

**有效期生成**

根据玩家提供的五行材质的**品质**和**数量**生成技能有效期，不提升技能效果。

- 品质越高、数量越多 → 有效期越长
- 最低：消耗 1 个最低品质五行材质 → 1 局有效
- 最高：永久有效

**失效与消耗**

一旦浸篆后，技能和材质均无法继续升级。失效后技能放回技能空间，五行材料被消耗。

**局间休整延长**

浸篆后会换算出有效期每局所消耗的五行材质品质和数量。局间休整时，可以通过消耗**同品质**五行材质 1.5 倍的每局数量来延长 1 局有效期。

**营地分解**

营地可以分解浸篆后永久有效的技能，但技能或材质只能选择保留其一。

**元素结算**

不论浸/篆，技能奇幻元素与材质五行属性均遵循 [五行作用于元素.md](五行作用于元素.md) 规范。释放技能时，按「五行材质 × 奇幻元素」交互矩阵修正最终威力。

`
进化/领域卡威力 = 技能基础威力
         × 变异卡加成（形态/体质加成）
         × 交互矩阵修正（五行材质 × 技能元素）

变异卡威力 = 角色当前形态/体质
         + 变异卡加成（形态/体质加成）
         × 交互矩阵修正（五行材质 × 技能元素）
`

### 2.4 五行相同材质升级系统

**材质品阶**

白 → 绿 → 蓝 → 紫 → 橙 → 红

**升级公式**

基础成功率 P = 100% −（目标档阶 × 10%）

| 升级 | 目标档阶 | 基础成功率 |
|---|---|---|
| 白 → 绿 | 1 档 | 90% |
| 绿 → 蓝 | 2 档 | 80% |
| 蓝 → 紫 | 3 档 | 70% |
| 紫 → 橙 | 4 档 | 60% |
| 橙 → 红 | 5 档 | 50% |

**升级消耗**

每提升一级，需额外提供**同品质同属性辅助材质 3 个**。

**失败处理**

失败时材料退回低一档。

**暴击/大成功**

依附于成功，只有成功才可能触发暴击（约 2%）/大成功（约 5%）。

- 大成功：跳过一档，蓝直冲橙
- 暴击：升级一档不变，但下次合成增加一定百分比成功率（具体数值后续考虑）

判定逻辑：先按基础成功率判定成功，成功后再 roll 特殊结果。

```csharp
if (!success) return Result.Fail;
return Rand() < 0.05 ? Result.Great : Result.Normal;
```

### 2.5 五行不同材质熔炼系统

**熔炼**

将**不同属性**的五行材质进行熔炼，产物同时具备两种属性，需计算两种属性的占比作为**背板属性**。

**熔炼后升级**

- 同品质熔炼材质可继续升级，升级时必须包含其中任意一种属性或两种属性
- 升级成功率**低于**同属性同品质材质的升级成功率
- 升级成功后，背板属性有一定几率回归单一属性材质：**单一属性占比超过 75% 时回归**
